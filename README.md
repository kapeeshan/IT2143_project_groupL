# IT2143_project_groupL
IT1243 group project ExamDesk app
Smart Quiz Management System

This project is a Smart Quiz Management System designed to simplify the process of creating, managing, and conducting quizzes. It provides an organized platform for admins, teachers, and students to interact with quizzes efficiently.

✔️ Key Features
 User-Friendly Interface – Simple and clean UI for easy navigation.

Quiz Creation & Management – Admins/teachers can add questions, edit quizzes, and manage categories.

Student Panel – Students can take quizzes, view results, and track progress.

Secure Login System – Role-based authentication for Admin, Teacher, and Student.

Real-Time Score Evaluation – Automatic scoring with detailed result screens.

Responsive Front-End – Smooth and modern UI built using WinForms (.NET Framework).

✔️ Technologies Used

Front-End: Windows Forms (.NET Framework)

Back-End: C#

Database: SQL Server

Version Control: Git & GitHub

✔️ Project Objectives

Provide a fast and efficient quiz system

Reduce manual work in question handling

Offer a modern UI for better user experience

Enable easy quiz monitoring and analytics
